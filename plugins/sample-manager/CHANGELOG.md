# Sample Manager Module Changelog

All notable changes to the Sample Manager plugin will be documented in this file.

## [1.6.0] - 2026-10-14

### Added
- **Inter-Plugin Service API**: Registered `sample_fetch_system_status` shared service endpoint.
- **Dynamic Widget Context**: Added user context widget hook on home dashboard.
- **Automated Lifecycle Hooks**: Added table creation on activation (`plug_sample_manager_logs`) and optional purge on deactivation.

## [1.0.0] - 2026-05-10

### Added
- **Initial Module Release**: Created Sample Manager plugin structure with custom route and background cleanup task.
